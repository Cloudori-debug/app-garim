# 암기노트 — 제품 스펙 (PRODUCT)

> SSOT 문서 3종 중 하나. 제품 정의·범위·수용 기준만 담는다.  
> **버전**: 1.3.0 · **무료 공개 출시** (2026-07-29)

## 한 줄 정의

내 PDF에 상자로 가리고, **잊기 전에 다시 물어보는** 로컬 암기 노트.

## 타깃

공시·수험생 — 이미 가진 요약/기출/이론서 PDF를 암기 도구로 전환.

## 핵심 가치 루프 (v1.1)

```text
오늘(due) → 복습(탭 공개 → 틀림/알았다)
서재 → Reader 편집(가림) → 학습 토글 → 즐겨찾기
```

## In Scope

### v1.0 (동결)

1. 폴더 트리 서재
2. PDF 등록·삭제 (Blob → IndexedDB)
3. PDF 보기 · 편집/학습 · 상자 가림 · 즐겨찾기

### v1.1

1. **오늘** 홈 — due 개수 + 복습 시작
2. ReviewState 테이블 + SM-2 단순(Again/Good)
3. 복습 세션 (공개 후 채점)
4. 색 테마 프리셋

### v1.2

1. **백업** — 더보기에서 JSON 내보내기 / 가져오기 (교체 복원)
2. PWA·아이패드 홈 화면 추가 안내
3. **한글 PDF cMap** — `/cmaps` · `/standard_fonts` (오프라인 동봉)
4. **고정 HTTPS 배포** — `npm run deploy` (Cloudflare Pages)

### v1.3 (무료 출시)

1. 오답·과목 통계
2. 학습/단어가림 일괄 열기·가리기
3. 더보기 → **의견 보내기** (메일)
4. 더보기 UI 출시용 정리

## Out of Scope (출시 직후 보류)

- 결제·라이선스 구현
- 클라우드 동기화·복습 알림 — **사용자 반응 후** 유료/무료 여부 결정

## 무료 · 유료 (방향)

**원칙**: 가림 → 학습 → 오늘 복습 **코어는 무료**.  
**타이밍**: 공개 출시 후 의견을 보고 유료화 또는 버전업을 결정한다.

| 티어 | 포함 | 목적 |
|------|------|------|
| **무료** (출시) | 서재·가림·복습·연습·테마·백업·통계·일괄 열기/닫기·의견 보내기 | 습관·피드백 |
| **유료 (후보)** | 알림, 클라우드 동기화·멀티기기, 자동 백업 등 | 반응 보고 확정 |

**가격 가설** (확정 전): 월 ₩2,000–5,000 **또는** 평생 ₩20,000–40,000.
