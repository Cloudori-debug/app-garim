# 암기노트 — 제품 스펙 (PRODUCT)

> SSOT 문서 3종 중 하나. 제품 정의·범위·수용 기준만 담는다.  
> **버전**: 1.2.0 · **진행 중** (2026-07-26)

## 한 줄 정의

내 PDF에 상자로 가리고, **잊기 전에 다시 물어보는** 로컬 암기 노트.

## 타깃

공시·수험생 — 이미 가진 요약/기출/이론서 PDF를 암기 도구로 전환.

## 핵심 가치 루프 (v1.1)

```text
오늘(due) → 복습(탭 공개 → 틀림/알았다)
서재 → Reader 편집(가림) → 학습 토글 → 즐겨찾기
```

## In Scope

### v1.0 (동결)

1. 폴더 트리 서재
2. PDF 등록·삭제 (Blob → IndexedDB)
3. PDF 보기 · 편집/학습 · 상자 가림 · 즐겨찾기

### v1.1

1. **오늘** 홈 — due 개수 + 복습 시작
2. ReviewState 테이블 + SM-2 단순(Again/Good)
3. 복습 세션 (공개 후 채점)
4. 색 테마 프리셋

### v1.2

1. **백업** — 더보기에서 JSON 내보내기 / 가져오기 (교체 복원)
2. PWA·아이패드 홈 화면 추가 안내
3. (예정) 한글 PDF cMap · 고정 HTTPS 배포

## Out of Scope (아직)

- FSRS, 알림, 오답 통계 대시보드
- OCR·AI, 계정·클라우드·결제
- 커스텀 컬러 피커
