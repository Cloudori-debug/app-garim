# 암기노트 시장조사 (2026-07-25)

> **범위**: 신규 제품 `amgi-note` 기획용. 기존 `app-garim` 코드/제품은 폐기 전제로, 시장만 독립 조사.  
> **조사일**: 2026-07-25 · **성격**: 1차 데스크 리서치 (스토어·공식사이트·업계 기사 기반)

---

## 1. 한 줄 결론

암기 앱 시장은 **(A) 내 교재 그대로 가림** · **(B) 플래시카드+SRS** · **(C) AI가 카드/문제 생성** · **(D) 기출/콘텐츠 구독** 네 층으로 갈라져 있다.  
국내에서 **“내 PDF/사진을 가리고 외운다”** 니즈는 살아 있으나, 강자는 **UI·광고·동기화·복습 스케줄**에서 각각 구멍이 있다.  
신규 진입은 **가림형 코어 + 진짜 복습(오늘 due) + 광고 없는 미니멀 UX** 조합이 가장 빈 자리로 보인다. AI 올인·기출 콘텐츠 올인은 자본·저작권 싸움이라 초기 비추.

## 2. 시장 구조

```text
┌─────────────────────────────────────────────────────────┐
│  D. 콘텐츠/기출 플랫폼                                    │
│     오르조 · 공풀 · 에듀윌 · 런투런 · 미북 · 클래스카드     │
│     (자료가 제품, 암기 도구는 부속)                        │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  C. AI 생성 → 암기/퀴즈                                   │
│     Memly · TikoNote · Eduloo · StudyGlen · AINO          │
│     (입력: PDF/유튜브/노트 → 출력: 카드·퀴즈·요약)         │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  B. 플래시카드 + 간격반복(SRS)                              │
│     Anki · RemNote · Quizlet · Noji · 암기짱 · Memor More │
│     (카드 단위 암기, 알고리즘이 핵심 자산)                  │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  A. 가림막 / Red Sheet / Image Occlusion                  │
│     합격노트 · 암기공책 · PDF Study(Red Sheet) · 메모리노트 │
│     (내 자료 레이아웃 유지, 영역만 가림)                    │
└─────────────────────────────────────────────────────────┘
```

| 세그먼트 | 사용자 행동 | 결제 동인 | 신규 진입 난이도 |
|----------|-------------|-----------|------------------|
| A 가림막 | 교재 PDF/사진 위에 박스 | 편의·필기·동기화 | **중** (기능 복제 쉬움, 차별화는 UX/복습) |
| B SRS 카드 | Q/A 카드 반복 | 장기 기억·습관 | 중~고 (Anki/FSRS가 표준) |
| C AI 생성 | 자료 올리고 자동 카드 | 시간 절약 | **고** (모델 비용·품질·차별화 소진) |
| D 기출 | 문제 풀이·회독 | 콘텐츠 양·해설 | **매우 고** (저작권·B2B) |

**공시/자격 시장 수요 신호** (스콘 설문, 2025 응시자 분석 기사):

- 태블릿 학습 활용 **92.2%**
- 연간 교재비 40만 원 이상 **59.6%**, 연평균 교재 **16.7권**
- → “이미 PDF·전자책·요약본을 많이 산다”는 전제. **카드를 다시 치는 비용**이 병목.

## 3. 경쟁사 맵 (핵심만)

### 3.1 A층 — 가림막형 (직접 경쟁)

| 제품 | 포지션 | 강점 | 약점 / 빈틈 | 수익 |
|------|--------|------|-------------|------|
| **합격노트** (2026, iOS) | “가림막으로 가리고 탭해서 외우는 암기노트” · 공시/자격/수능 | PDF·사진, 가림막, 평가(셀프채점)·오답 재학습, 필기, iCloud, 로그인 없이 | 리뷰 적음(초창기), Android 약함, SRS급 자동 due 미강조 | 무료 시작 |
| **암기 공책** (별책) | iPad+Pencil 마스킹 필기 | 텍스트 롱탭 자동 마스킹, 오답·중요도, 내비게이터 정렬, iCloud | iPhone 필기 제한, 평점 표본 부족, 광고/가격 정보 빈약 | 무료(IAP 미명시) |
| **PDF Study: Red Sheet** | 글로벌 빨간시트 PDF 암기 | 블록 토글, 세로 스크롤 복습, 다국어 | **광고**, 구독 난립(월 ~$3–7), SRS·오답 큐 약함 | Freemium+Ads |
| **메모리노트** (메타마인드) | 의대 Anki식 Image Occlusion | 이미지 가림 빈칸 | Anki/의대 맥락, 일반 공시 UX와 거리 | — |

### 3.2 B층 — 카드/SRS (간접 경쟁, “왜 카드로 안 옮기냐”의 대안)

| 제품 | 강점 | 약점 | 가격 참고 |
|------|------|------|-----------|
| **Anki** | FSRS 표준, 오프라인, 확장 | UX 가파름, 카드 제작 시간, iOS 유료(~$25) | 데스크톱 무료 |
| **RemNote** | 노트+인라인 카드, FSRS | 무거움, 영미권·의대 톤 | Pro ~$8–12/월 |
| **Noji** | 국내 리뷰 강(자격·고시), 현대 UI | 카드 중심(교재 레이아웃 X), 구독 | 구독형 |
| **암기짱** | 폴더·푸시·웹 작성·백업 | 단순 SRS, AI/가림 없음 | — |
| **Quizlet** | 공유 세트·진입 쉬움 | 진짜 SRS 약함, AI/Learn 페이월 | Plus ~$8/월 |

### 3.3 C층 — AI 생성 (트렌드 경쟁, 코어 대체 아님)

| 제품 | 한 줄 | 시사점 |
|------|-------|--------|
| Memly / TikoNote / Eduloo / StudyGlen | PDF·유튜브 → 카드·퀴즈 + FSRS | “만들기 귀찮음” 해결. **스캔 PDF·표·도표·기출 레이아웃**에서는 품질 불안정 |
| AINO | 강의 요약·기기 내 Apple Intelligence | 노트/강의축, 가림 암기와 겹침 적음 |

### 3.4 D층 — 기출/학원 (대체재가 아님)

오르조·공풀·에듀윌·런투런·미북·클래스카드는 **문제가 상품**.  
암기노트는 “내가 산 요약/이론 PDF를 도구로 바꾼다”는 **도구형**이라 직접 대결하지 않고, 오히려 **병행 사용**이 자연스럽다.

## 4. 사용자 니즈 (페르소나)

### P1. 공시·자격 암기형 (1차 타깃 후보)

- 자료: 학원 요약 PDF, 기출 해설 PDF, 스캔 이론서
- 행동: 빨간펜/형광펜 → 손으로 가리고 회상, 태블릿 회독
- Pain: Anki 카드화에 시간 과다 / 레이아웃·표·도식이 깨지면 기억 단서 상실 / “오늘 뭐 복습하지?” 없음

### P2. 대학·전공 시험 벼락치기

- 짧은 기간, 교수 슬라이드·필기 사진
- Pain: 앱이 무겁거나 계정·구독 장벽 / 광고로 집중 깨짐

### P3. 의대·전문직 Anki 유저

- 이미 Anki/IOE 생태계
- → **초기 타깃에서 제외** (전환 비용 극대)

### P4. 중고등·학원 단어

- 클래스카드·Quizlet 점유
- → B2B/콘텐츠 싸움, 초기 비추

## 5. 반복되는 Pain (스토어·리뷰·업계 공통)

1. **카드 제작 비용**: “자료는 있는데 카드를 다시 치는 게 공부보다 김”
2. **레이아웃 의존 암기**: 표·조문·도식은 가림이 카드보다 자연스러움
3. **복습 스케줄 부재**: 가림 앱은 “탭해서 보기”까지는 잘 함. **due 큐·망각곡선**은 카드 앱에 치우침
4. **광고·구독 압박**: PDF Study류 — 광고가 학습 흐름을 끊음 (평점 하락 요인)
5. **기능 과밀**: 필기+마스킹+동기화+꾸미기 → 첫 세션까지 탭이 많음
6. **크로스플랫폼**: iPad 중심(암기공책) vs Android/웹 공시생 공존
7. **AI 품질 불신**: 자동 카드가 시험 포인트와 어긋나면 신뢰 붕괴 → 수정 노동 발생

## 6. 기회 공간 (Opportunity)

| 기회 | 설명 | 경쟁 대비 |
|------|------|-----------|
| **O1. 가림 + 진짜 복습** | 박스 단위로 due / Again / Hard / Easy 또는 O/X → SM-2 또는 FSRS | 합격노트는 평가·오답은 있으나 Anki급 스케줄 약함. PDF Study는 거의 없음 |
| **O2. 광고 제로 + 빠른 첫 루프** | 가져오기 → 가림 1개 → 탭 회상까지 60초 | PDF Study 대비 명확 |
| **O3. 페이지 일괄 열기/닫기** | 암기공책 리뷰성 요청으로 자주 언급되는 UX | 구현 난이도 낮고 체감 큼 |
| **O4. 오프라인·로컬 우선** | 독서실·지하철, 로그인 없이 | 합격노트와 유사 — 차별은 복습 엔진 |
| **O5. “도구형” 포지션** | 오르조와 싸우지 않음. “네 교재 위에 암기 레이어” | D층과 보완재 |

**비기회 (초기 Avoid)**

- 기출 DB 구축
- AI 자동 빈칸을 코어로 (보조는 후순위)
- Anki 호환·의대 IOE 전면전
- 학원 B2B (클래스카드 영역)

## 7. 가격·수익 벤치마크

| 유형 | 사례 | 구간 |
|------|------|------|
| 광고+저가 구독 | PDF Study | 월 약 $3–7 / 반년 묶음 |
| 노트+SRS Pro | RemNote | ~$8–12/월, AI 상위 ~$19 |
| 국내 AI 암기 | 달달암기 | 월 ₩7,900 / ₩13,900 |
| 카드 앱 구독 | Noji, Quizlet Plus | 월 수천~1만 원대 |
| 일회성 | Anki iOS | ~$25 |
| 공시 기출앱 | 오르조 등 | 콘텐츠 구독 (도구와 별개) |

**해석**: 도구형 암기노트는 **무료로 가림·회상 전체를 열고**, **자동 복습 큐·통계·알림·멀티기기**를 유료로 두는 구조가 설득력 있음.  
국내 수험 도구는 글로벌 RemNote보다 **낮은 월액(₩2,000–5,000)** 또는 **합격 주기 맞는 평생권(₩2–4만)** 병행이 현실적.

## 8. 포지셔닝 초안 (시장조사 기반 가설)

> **한 줄**: “카드를 다시 만들지 말고, 가진 PDF·사진 그대로 가리고 — 잊기 전에 다시 물어주는 암기노트.”

| 축 | 선택 가설 |
|----|-----------|
| 카테고리 | A(가림) ∩ B(SRS) — **하이브리드 도구** |
| 타깃 | 공시·자격·전공 암기 (태블릿 중심, 폰은 복습) |
| 비타깃 | Anki 헤비유저, 학원 영어 단어, 기출 풀이 전용 |
| 대결 | PDF Study(광고)·단순 가림앱(복습 없음)·Anki(제작 비용) |
| 하지 않을 것 | AI 올인, 콘텐츠 판매, 소셜 공유 덱 |

검증 필요 KPI (다음 단계에서 유저 인터뷰):

1. “지금 암기는 어떻게 하냐?” → 빨간시트/손으로 가림 비중
2. Anki/Noji 이탈 사유 = 카드 제작인가 UX인가
3. 월 ₩3,000 복습 자동화를 살 의향

## 9. 기능 우선순위 시사 (구현 전 기획용)

**Must (MVP 후보)**

1. PDF·이미지 가져오기 (로컬)
2. 드래그 가림막 + 탭 토글
3. 서재(과목/폴더)
4. 셀프 채점 → **오늘 복습 큐** (최소 SM-2 수준)
5. 오프라인, 로그인 불필요

**Should**

- 페이지 일괄 가림/공개
- 오답·중요도 정렬
- 간단 통계(틀린 박스 Top N)
- 백업/내보내기

**Later**

- Apple Pencil 필기
- iCloud/계정 동기화
- OCR 텍스트 선택 가림
- AI 보조 빈칸 (사용자 확정 후에만)
- Android 네이티브 / PWA
