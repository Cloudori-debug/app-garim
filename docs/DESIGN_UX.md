> **성격**: 화면·인터랙션·비주얼 기준. 코드 구현 지시서 아님.

## 0. 전제

니즈·포지션은 이미 충분하다. 제품이 지는 지점은 **기능 목록이 아니라**,

1. 가림을 그리는 손맛  
2. 학습 중 손이 어디에 가는지  
3. 앱을 열었을 때 “오늘 뭐 하지?”가 0초인지  
4. PDF가 주인공인데 UI가 방해하지 않는지  

이 네 가지다.

---

## 1. 디자인 원칙 (강제)

| # | 원칙 | 구체 |
|---|------|------|
| 1 | **PDF가 화면의 80%** | 크롬(툴바·패널)은 얇고, 필요할 때만 나타남 |
| 2 | **한 화면 한 일** | 홈=오늘 복습 / 서재=자료 / 리더=가림·학습. 설정·통계는 깊이 넣음 |
| 3 | **탭 3번 안에 회상** | 앱 실행 → 복습 시작 → 첫 가림 탭 |
| 4 | **편집 ≠ 학습** | 모드가 시각적으로 一眼 구분 (색·라벨·하단 바 구성이 다름) |
| 5 | **손가락 우선** | 태블릿 기본. 가림 핸들·채점 버튼은 엄지 존(하단·우측) |
| 6 | **조용한 UI** | 광고·배너·치어업 없음. 장식 카드·통계 스트립 남발 금지 |
| 7 | **실수 복구** | 가림 삭제·채점은 되돌리기(Undo) 가능 |

경쟁이 자주 지는 지점(암기공책 과밀, PDF Study 광고, Anki 진입장벽)을 **미니멀·끊김 없음**으로 친다.

## 2. 비주얼 방향

### 2.1 톤

- **수험 도구**: 차분, 읽기 좋음, “시험장 책상” 느낌  
- **브랜드 신호**: 이름/워드마크는 홈·스플래시에만 또렷. 리더 안에서는 거의  Invisible  
- **피하기** (AI 기본값 클러스터): 보라 그라데이션, 크림+세리프+테라코타, 다크네온 글로우, 알약 뱃지 잔뜩, 이모지 UI

### 2.2 컬러 토큰 (초안)

| 토큰 | 역할 | 방향 |
|------|------|------|
| `--bg` | 앱 배경 | 웜 뉴트럴이 아닌 **쿨 오프화이트** 또는 아주 옅은 슬레이트 (`#F4F5F7` 근처) |
| `--surface` | 패널·시트 | 흰색, 헤어라인 보더만 |
| `--ink` | 본문 | `#1A1D21` |
| `--muted` | 보조 라벨 | `#6B7280` |
| `--accent` | CTA·오늘 복습 | **테마별** (§2.3). 기본 틸 `#0F766E`. 보라 금지 |
| `--mask` | 가림 기본 | 불투명 슬레이트 / 선택 시 accent 링 |
| `--danger` | 삭제·틀림 | 절제된 레드, 채점 “틀림”에만 (테마 공통) |
| `--ok` | 알았다 | accent와 동일 계열 |

가림 색은 **최대 3색** (기본·중요·약점). 彩虹 팔레트 금지.

### 2.3 색 테마 (교체 가능)

배경·잉크·마스킹·danger는 **공통**. accent(및 ok / soft)만 테마로 바꿈.  
구현: `html[data-theme="…"]` + CSS 변수. 미리보기: [hifi-review.html](./wireframes/hifi-review.html) · 토큰 파일: [themes.css](./wireframes/themes.css)

| id | 이름 | Accent | 느낌 |
|----|------|--------|------|
| `teal` | 틸 (**기본**) | `#0F766E` | 차분한 수험 도구 (현재 확정 기본) |
| `ink` | 잉크 | `#1D4E89` | 잉크·필기 연상 |
| `forest` | 포레스트 | `#166534` | 길게 앉아도 눈이 편한 그린 |
| `navy` | 네이비 | `#1E3A5F` | 더 무게감 있는 딥 블루 |
| `graphite` | 그래파이트 | `#3F3F46` | 거의 모노, UI가 더  Quiet |

**규칙**

- 설정에서 테마 선택 → `localStorage['amgi-theme']` (또는 동등)에 id 저장
- 런타임에 `document.documentElement.dataset.theme = id`
- 커스텀 컬러 피커는 MVP 비범위 — **프리셋만**
- 금지 톤: 보라 그라데이션, 크림+테라코타 세트, 네온/글로우

### 2.4 타이포

- UI: 가독성 좋은 **고딕 한 계열** (예: Pretendard / IBM Plex Sans KR). 디스플레이 세리프로 브랜드 과시하지 않음  
- 크기: 홈 숫자(오늘 N개)만 크게. 나머지는 밀도 있게  
- PDF 위 텍스트와 싸우지 않게, 오버레이 라벨은 짧고 굵게

### 2.5 모션 (2~3개만)

1. 복습 시작 → 리더로 **짧은 페이드/슬라이드** (200ms)  
2. 가림 탭 → **opacity 토글** (스프링 과함 금지)  
3. 채점 후 → 다음 가림으로 **시선이 따라가게** 약한 하이라이트 펄스 1회  

장식용 패럴랙스·컨페티 없음.

## 3. 정보 구조

```text
탭(하단, 태블릿·폰 공통)
├── 오늘     ← 기본 진입
├── 서재
└── 더보기   (백업·설정 — MVP는 최소)
```

| 화면 | 한 일 | 위에 올리면 안 되는 것 |
|------|------|------------------------|
| **오늘** | 복습 시작 + 남은 개수 | 과목 통계 대시보드, 팁 카드 여러 장 |
| **서재** | 과목·문서 찾기·가져오기 | 편집 도구 |
| **리더·편집** | 가림 그리기 | 채점 UI |
| **리더·학습** | 탭 회상·(선택) 채점 | 색상 피커·핸들 |
| **복습 세션** | 큐만 돌리기 | 서재 탐색 |

## 4. 핵심 동선 (사용편의성)

### 4.1 첫 실행 (60초 목표)

```text
빈 오늘 화면
  → [PDF 가져오기] 하나
  → 과목 이름 묻기 (또는 "기본")
  → 리더 편집 모드 + 첫 가림 유도 (점선 힌트 1회)
  → [학습으로] → 탭 한 번
```

온보딩 캐러셀 3장 **금지**. 샘플 PDF는 선택(나중에).

### 4.2 매일 (공시 습관)

```text
앱 열림 = 오늘
  → [복습 시작] (큰 버튼)
  → 가림 보임(가려진 상태) → 회상 → 탭 공개
  → [알았다] / [틀림] (엄지 존)
  → 다음 … → 완료 한 줄 ("내일 N개")
```

홈에 과목 목록을 잔뜩 두지 않음. **숫자 + 시작**이 히어로.

### 4.3 편집 (회독 준비)

- 기본은 **학습**. 편집은 명시 전환  
- 드래그 = 새 가림, 탭(편집) = 선택, 핸들로 리사이즈  
- 페이지 **일괄 가림/공개**는 v0.2지만, 자리만 툴바에 예약 가능  

### 4.4 제스처 규칙

| 제스처 | 학습 | 편집 |
|--------|------|------|
| 한 손가락 탭 | 가림 토글 | 선택 |
| 한 손가락 드래그 | (없음/팬 금지) | 가림 생성 |
| 두 손가락 핀치·팬 | 줌·이동 | 줌·이동 |
| 스와이프 | 페이지 (명확할 때만) | 페이지 |

학습 중 실수로 가림이 생기면 안 되므로, **학습에서는 드래그 생성 잠금**.

## 5. 화면별 UI 스케치

### 5.1 오늘

```text
┌─────────────────────────────┐
│ 암기노트              더보기 │
│                             │
│      오늘 복습              │
│         24                  │
│     [ 복습 시작 ]           │
│                             │
│  과목별  한국사 12 · 행정 8 │
│  (작게, 탭 시 필터)         │
└─────────────────────────────┘
│  오늘  │  서재  │  더보기  │
```

- `24`가 브랜드보다 큼  
- 0개일 때: “서재에서 가림을 만들면 여기에 모여요” + [서재로]

### 5.2 서재

- 왼쪽(또는 위): 과목 칩/리스트  
- 오른쪽: 문서 카드는 **파일명 + 가림 수 + 마지막 학습**만. 표지 꾸미기·그라데이션 카드 남발 없음  
- FAB 또는 상단: [가져오기]

### 5.3 리더 — 편집

```text
┌ 과목/파일명     학습으로 ─┐
│ [가림] [색] [삭제] [⋯]   │  ← 얇은 툴바
│                           │
│         PDF               │
│      ┌─────┐              │
│      │가림 │              │
│      └─────┘              │
│                           │
│ ‹ 12 / 40 ›               │
└───────────────────────────┘
```

### 5.4 리더 — 학습 / 복습 세션

```text
┌ 복습 3/24          편집 ─┐
│                           │
│         PDF + 가림        │
│                           │
│                           │
│  ┌────────┐ ┌────────┐   │  ← 하단 엄지 존
│  │ 틀림   │ │ 알았다 │   │
│  └────────┘ └────────┘   │
└───────────────────────────┘
```

- 채점 전: 가림 탭으로만 공개/비공개  
- 공개 후 채점 버튼 활성화 (또는 탭=공개, 버튼=채점 분리 — **후자를 기본**으로 해 실수 채점↓)

## 6. 사용편의성 체크리스트 (수용에 가깝게)

구현·디자인 리뷰 때 이 목록으로 PASS/FAIL.

- [ ] 콜드 스타트: 설명 읽지 않고 첫 가림까지 ≤ 60초  
- [ ] 재방문: 스플래시 후 **오늘**이 기본, 탭 ≤ 1로 복습 시작  
- [ ] 학습 중 한 손(엄지)으로 알았다/틀림 가능 (태블릿 가로·세로 각각)  
- [ ] 편집/학습 전환이 라벨 없이도 색·하단 바로 구분  
- [ ] PDF 줌해도 가림 좌표 어긋나지 않음  
- [ ] 가림 10개+ 페이지에서 스크롤·토글 버벅임 체감 없음 (목표)  
- [ ] 광고·업셀 시트·강제 온보딩 없음  
- [ ] 다크 모드: MVP 비필수. 있으면 PDF 가독 우선, UI만 반전
